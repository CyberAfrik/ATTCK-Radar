# Règles CyberAfrik

Déposez ici vos règles Sigma (`.yml`). Elles sont converties vers tous les langages pris en charge
à chaque reconstruction du référentiel, comme les règles SigmaHQ.

Chaque règle doit avoir un `id` (UUID) unique, un `title`, un `logsource`, un bloc `detection`,
un `level` et des `tags` ATT&CK (par exemple `attack.t1558.003`). Le champ `license` est facultatif (MIT par défaut).
